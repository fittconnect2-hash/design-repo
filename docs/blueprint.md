# **App Name**: DesignDock

## Core Features:

- Add New Design Project: A dedicated form to input details including project name, description, Figma link, prototype URL, and upload an associated image.
- Design Project List Display: A table-like view displaying a summary of all added design projects, including name, description, and a thumbnail of the uploaded image.
- View Design Project Details: Allow users to select an entry from the list to view all project details, including links and the full-size image, on a separate page.
- Edit Design Project Information: Functionality to modify the name, description, links, and associated image of an existing design project entry.
- Delete Design Project: Option to remove a design project entry from the system.
- AI-Powered Tag Suggestion Tool: An AI tool that suggests relevant tags or keywords for design projects based on the provided name and description, enhancing searchability and categorization.
- Persistent Data Storage: Secure storage for all design project data, including text fields and image references.

## Style Guidelines:

- Primary color: Muted blue-grey (#4D6B80), conveying professionalism and calm for a creative management tool. (HSL: 220, 40%, 50%)
- Background color: Very light blue-grey (#ECF1F3), providing a clean and subtle backdrop. (HSL: 220, 20%, 95%)
- Accent color: Vibrant sky blue (#66C4E2), offering a refreshing contrast for interactive elements and highlights. (HSL: 190, 60%, 65%)
- Body and headline font: 'Inter' (sans-serif), chosen for its modern, clean, and highly readable aesthetic, suitable for technical details and project descriptions.
- Use clean, minimalist line icons for navigation and actions (e.g., 'add', 'edit', 'delete', 'link' icons) to maintain a modern and professional appearance.
- Implement a structured, minimalist layout with ample whitespace. The main project list should be tabular, with a clear form for adding new entries, possibly within a modal or dedicated page.
- Subtle and functional animations, such as smooth transitions for modal openings/closings and gentle fades when updating list items, to enhance user experience without distraction.
